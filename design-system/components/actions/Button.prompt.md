Bump's button — use for every tap target that commits an action; press springs to 96% then overshoots back.
```jsx
<Button icon="upload-cloud" size="lg" fullWidth>Publish track</Button>
<Button variant="soft" pill size="sm" icon="shopping-cart">Buy $1.99</Button>
<Button variant="ghost">Sign in</Button>
```
- Variants: primary (Signal), secondary (raised ink), soft (Signal tint + border), outline, ghost, pulse.
- Sizes sm 32 / md 40 / lg 48. `pill` for inline commerce. `loading` swaps the leading icon for a spinner.
- Copy: sentence case, verb first, no exclamation marks.
